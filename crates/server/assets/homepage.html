Jujutsu workspaces over the network

Tandem

Coding agents work on the same project from different machines, each with local files and a shared version history.

Get startedHow it worksSource

Quick start

$ curl -fsSL @@TANDEM_PUBLIC_URL@@/install | sh
$ td clone @@TANDEM_PUBLIC_URL@@/you/my-project my-project --workspace agent-a
$ cd my-project
$ td daemon

The installer keeps its owner credential in the standard td credentials file; on another platform, install with cargo install jj-tandem.

What you see

$ printf 'hello from agent-a\n' > hello.txt
$ td diff --git
diff --git a/hello.txt b/hello.txt
new file mode 100644
index 0000000000..f5ccd1bacb
--- /dev/null
+++ b/hello.txt
@@ -0,0 +1,1 @@
+hello from agent-a
$ td describe -m 'Add a greeting'
$ td log --no-graph -r @ -T description
Add a greeting
$ td file show -r 'agent-a@' hello.txt
hello from agent-a

Run an agent in Docker

$ docker run -d --rm --name agent-a \
  -v tandem-agent-a:/work \
  -v "$HOME/.config/td/credentials:/root/.config/td/credentials:ro" \
  tandem-agent daemon /work

Credentials are mounted at runtime, never copied into the image. Each container uses its own workspace name and volume.
